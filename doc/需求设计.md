# 月度财务报表自动生成工具 方案与需求设计

**版本**：V1.0  
**形态**：Windows 本地桌面工具（单目录文件夹分发）  
**核心目标**：根据资产负债表、利润表、现金流量表、科目余额表模板，自动计算并生成月度财务报表；全程本地运行、不联网、不上传；提供计算自校验和计算逻辑日志留存，确保结果可复核、可追溯。

---

## 1. 方案设计

### 1.1 技术选型

| 项 | 选择 |
|---|---|
| 语言 | Python |
| 界面 | PySide6（推荐）或 Tkinter |
| Excel 读写 | pandas + openpyxl |
| 金额计算 | `decimal.Decimal`，禁止二进制浮点直接计算 |
| 打包 | PyInstaller `--onedir`，输出单目录文件夹，主程序 `FinancialReportTool.exe` |
| 分发 | ZIP 便携包；需要安装体验时可用 Inno Setup 封装 |
| 网络 | 全程不发起网络请求 |

### 1.2 分层架构

| 层 | 职责 |
|---|---|
| UI 层 | 文件选择、月份输入、生成、校验结果展示、日志查看 |
| 应用服务层 | 编排生成流程、控制阻断/确认、生成 `run_id` |
| 解析层 | 读取四张 Excel，识别 Sheet、列、单元格 |
| 计算引擎层 | 按映射规则取数、汇总、公式计算 |
| 校验层 | 执行自校验规则，输出 E/W/I 分级结果 |
| 日志层 | 操作日志、计算日志、校验日志、异常日志、审计摘要 |
| 配置层 | 加载并校验 `mapping.json`、`settings.json` |
| 输出层 | 写入报表模板副本，保留格式，保存输出文件 |

计算、校验、日志模块不依赖 UI，便于测试和维护。

### 1.3 目录结构

```text

├── config/

│   └── cash_flow_template.xlsx
├── logs/

│   └── audit/

└── README.txt
```

### 1.4 处理流程

1. 用户选择四张 Excel，输入报表月份，选择输出目录。
2. 校验文件、Sheet、列完整性。
3. 加载并校验映射配置。
4. 读取科目余额表，执行试算平衡校验。
5. 按映射规则计算三张报表项目，逐项写计算日志。
6. 执行报表勾稽校验和跨表校验。
7. 存在 E 级错误则阻断；存在 W 级警告需用户确认后继续。
8. 将结果写入报表模板副本，保留原格式，保存到输出目录。
9. 重新读取输出文件复核关键单元格。
10. 生成审计摘要，展示 `run_id`、输出路径、校验结论、日志路径。

## 2. 需求设计

### 2.1 功能需求清单

| 编号 | 功能 | 优先级 |
|---|---|---|
| FR-01 | 文件选择与输入管理 | 必须 |
| FR-02 | 模板解析与结构识别 | 必须 |
| FR-03 | 映射配置加载与校验 | 必须 |
| FR-04 | 科目余额表试算平衡校验 | 必须 |
| FR-05 | 报表项目计算引擎 | 必须 |
| FR-06 | 自校验体系 | 必须 |
| FR-07 | 报表生成与输出 | 必须 |
| FR-08 | 计算逻辑日志留存 | 必须 |
| FR-09 | 操作日志与异常日志 | 必须 |
| FR-10 | 日志查看与审计包导出 | 必须 |
| FR-11 | 配置管理与版本记录 | 必须 |
| FR-12 | 生成前确认与生成后摘要 | 必须 |

### 2.2 文件选择与输入管理

- 四个文件入口：资产负债表模板、利润表模板、现金流量表模板、科目余额表。
- 支持 `.xlsx`；`.xls` 提示另存为 `.xlsx`。
- 三张财务报表模板支持使用 `templates/` 内置模板；科目余额表必须用户选择。
- 输入报表月份 `YYYY-MM`，用于输出命名和日志元信息。
- 输出目录默认 `output/`，生成前检查可写。
- 记录每个输入文件 SHA256，写入审计摘要和计算日志头部。

### 2.3 模板解析与结构识别

**科目余额表**

- 必需 Sheet 可配置，默认第一个 Sheet。
- 必需列（列名支持别名配置）：科目编码、科目名称、期初借方、期初贷方、本期借方发生、本期贷方发生、期末借方、期末贷方。
- 金额列空值按 0 处理，非数值报错并给出行号。
- 科目编码按文本读取，避免前导零丢失。

**财务报表模板**

- 通过配置定义“报表项目 → 单元格地址”，如 `资产负债表!B5`。
- 支持合并单元格取值/写入，写入保留原样式。
- 配置标记 `readonly` 的固定行、公式行不得覆盖。

### 2.4 映射配置

`mapping.json` 定义三张报表每个项目的取数规则，支持：

- 科目编码前缀匹配；
- 科目名称精确/包含匹配（辅助）；
- 取数字段：期初借方/贷方、本期借方/贷方发生、期末借方/贷方；
- 符号控制 `sign`；
- 汇总方式：求和、直接取值、固定值、公式引用其他项目；
- 忽略清单 `ignore_accounts`，避免未映射误报。

示例：

```json
{
  "config_version": "2026.11.1",
  "reports": {
    "balance_sheet": {
      "name": "资产负债表",
      "items": [
        {
          "item": "货币资金",
          "cell": "B5",
          "expression": "SUM",
          "sources": [
            {"account_prefix": "1001", "field": "期末借方", "sign": 1},
            {"account_prefix": "1002", "field": "期末借方", "sign": 1},
            {"account_prefix": "1012", "field": "期末借方", "sign": 1}
          ]
        }
      ]
    }
  },
  "ignore_accounts": ["6901", "6902"]
}
```

配置加载时执行 JSON Schema 校验；记录配置版本号和 SHA256，写入审计摘要。

### 2.5 计算引擎

- 按映射规则逐项计算，金额使用 `Decimal`，中间结果保留至少 6 位小数，最终 `ROUND_HALF_UP` 到 2 位。
- 每个项目记录：报表、项目、目标单元格、表达式、每个源科目的编码/名称/字段/原始金额/符号、汇总结果、状态。
- 公式型项目支持四则运算和已计算项目引用，只允许白名单函数（`SUM`、`ABS`、`ROUND`），不允许任意代码执行。
- 公式引用必须做循环引用检测，检测到循环则阻断。
- 固定值项目标记 `fixed` 并记录来源说明。
- 源科目无匹配时按配置分级：E 阻断 / W 警告并写 0 / I 提示。

### 2.6 自校验规则

| 编号 | 规则 | 级别 |
|---|---|---|
| VC-01 | 文件存在且可读 | E |
| VC-02 | 文件格式为 `.xlsx` | E |
| VC-03 | 必需 Sheet 存在 | E |
| VC-04 | 科目余额表必需列存在 | E |
| VC-05 | 金额列数据类型合法 | E |
| VC-06 | 科目编码非空且唯一 | E（空）/ W（重复） |
| VC-07 | 期初试算平衡，差额 ≤ 0.01 | E |
| VC-08 | 本期发生试算平衡，差额 ≤ 0.01 | E |
| VC-09 | 期末试算平衡，差额 ≤ 0.01 | E |
| VC-10 | 映射配置 JSON Schema 合法 | E |
| VC-11 | 映射目标报表/单元格存在 | E |
| VC-12 | 映射源科目至少匹配一个科目 | E |
| VC-13 | 映射源科目在科目余额表中不存在 | W |
| VC-14 | 同一科目被多个互斥项目重复映射 | W |
| VC-15 | 有余额/发生额的科目未映射且不在忽略清单 | W（可配置为 E） |
| VC-16 | 公式循环引用 | E |
| VC-17 | 资产负债表平衡 | E |
| VC-18 | 利润表勾稽 | E |
| VC-19 | 现金流量表勾稽 | E |
| VC-20 | 跨表勾稽（可配置） | W |
| VC-21 | 输出文件写入后复核 | E |
| VC-22 | 输出目录可写 | E |
| VC-23 | 模板只读单元格未被覆盖 | E |
| VC-24 | 金额精度检查 | W |

校验结果含规则编号、级别、标题、描述、详情、时间戳。UI 表格展示，E 级红色、W 级橙色、I 级灰色；存在 E 级时禁用生成。

### 2.7 报表生成与输出

- 不修改用户选择的模板源文件，以模板副本写入。
- 输出文件名：`{报表名称}_{YYYY-MM}_生成_{run_id}.xlsx`。
- 默认三张报表分别输出，保持与模板一致。
- 保留原单元格样式、列宽、合并单元格、打印设置，仅覆盖配置指定的数值单元格。
- 先写临时文件，输出复核通过后重命名，避免产生半成品。
- 写入后重新读取关键单元格，与计算结果差异 > 0.01 则报 E。
- 计算输出文件 SHA256，写入审计摘要。

### 2.8 日志留存

| 日志类型 | 路径 | 内容 |
|---|---|---|
| 操作日志 | `logs/app/app_YYYYMMDD.log` | 启动/退出、文件选择、生成开始/结束、警告确认、配置变更、导出 |
| 计算日志 | `logs/calc/YYYY/MM/{run_id}.jsonl` | 逐项取数、表达式、源科目明细、中间结果、最终结果 |
| 校验日志 | `logs/validation/YYYY/MM/{run_id}.jsonl` | 每条校验规则结果与详情 |
| 异常日志 | `logs/error/error.log` | 异常堆栈、模块、`run_id`，按大小轮转 |
| 审计摘要 | `logs/audit/YYYY/MM/{run_id}_summary.json` | 输入/配置/输出/日志哈希、校验结论、软件版本 |

要求：

- 每次生成无论成功或失败，都产生计算日志和校验日志；成功生成额外产生审计摘要。
- 计算日志金额以字符串保存，避免 JSON 浮点精度问题。
- 日志按 `run_id` 独立成文件，便于审计包按次打包。
- 默认保留 365 天，审计摘要默认保留 3 年，可在 `settings.json` 配置。
- 日志仅存本地，程序不联网，界面提示用户妥善保管日志目录。

**计算日志示例：**

```json
{
  "run_id": "20261123_153000_ab12cd",
  "stage": "CALC_ITEM",
  "report": "资产负债表",
  "item": "货币资金",
  "cell": "B5",
  "expression": "SUM(1001期末借方, 1002期末借方, 1012期末借方)",
  "source_accounts": [
    {"code": "1001", "name": "库存现金", "field": "期末借方", "raw_amount": "1234.56", "sign": 1, "amount": "1234.56"},
    {"code": "1002", "name": "银行存款", "field": "期末借方", "raw_amount": "80000.00", "sign": 1, "amount": "80000.00"}
  ],
  "result": "81234.56",
  "status": "OK"
}
```

### 2.9 日志查看与审计包

- 按 `run_id` 列出历史运行，显示时间、月份、状态、校验结论、输出文件数。
- 选中运行后展示三个 Tab：校验结果、计算明细、审计摘要。
- 计算明细支持筛选和导出 CSV。
- 支持“导出审计包”ZIP，包含：审计摘要、输入文件哈希清单、映射配置副本、设置副本、计算日志、校验日志、输出文件哈希清单、审计说明。

### 2.10 界面需求

**主界面**

- 四个文件选择行，显示路径；“使用内置模板”仅用于三张报表模板。
- 报表月份、输出目录。
- 按钮：配置自检、开始生成、查看日志、导出审计包。
- 校验结果表格，支持按级别筛选。
- 状态栏：当前步骤、耗时、`run_id`。

**生成过程**

- 显示步骤进度：解析输入 → 校验配置 → 试算平衡 → 计算报表 → 勾稽校验 → 写入输出 → 输出复核 → 写审计摘要。
- 耗时操作在工作线程执行，UI 不假死。

**日志窗口**

- 左侧运行列表，右侧 Tab；支持日期/状态筛选、打开日志目录、导出计算明细 CSV、导出审计包。

**设置窗口**

- 日志保留天数、校验阈值（默认 0.01，修改需二次确认）、默认输出目录、生成成功后是否自动打开输出目录。
- 设置修改记入操作日志，并更新 `settings.json` 哈希。

### 2.11 非功能需求

| 编号 | 需求 | 指标 |
|---|---|---|
| NFR-01 | 性能 | 科目 ≤ 5000 行时生成 ≤ 10 秒；启动 ≤ 5 秒 |
| NFR-02 | 可靠性 | 异常不崩溃；生成失败不产生半成品输出 |
| NFR-03 | 准确性 | 金额使用 Decimal；输出保留 2 位；阈值可配置 |
| NFR-04 | 兼容性 | Windows 10/11 64 位；Excel 2016+ 可打开输出；高 DPI 适配 |
| NFR-05 | 易用性 | 主流程不超过 5 次点击；错误含规则编号和可操作提示 |
| NFR-06 | 可维护性 | 计算/校验/日志与 UI 解耦；映射外置；关键模块有单元测试 |
| NFR-07 | 安全隐私 | 不联网、不上传、不收集；日志本地存储 |
| NFR-08 | 可追溯性 | 每次运行唯一 `run_id`；输入/配置/输出/日志哈希可查 |
| NFR-09 | 日志完整性 | 成功和失败均留计算与校验日志；审计摘要含日志哈希 |
| NFR-10 | 可移植性 | 单目录复制到无 Python 的 Windows 电脑可运行 |

### 2.12 验收标准

1. 选择四张样例表，输入月份，10 秒内输出三张报表，格式与模板一致。
2. 输出报表关键项目与手工计算一致，误差 ≤ 0.01。
3. 科目余额表试算不平衡时生成被阻断，并显示差额。
4. 未映射科目按配置产生 W 或 E；W 需确认后才能生成。
5. 每次运行产生计算日志和校验日志；成功运行产生审计摘要。
6. 计算日志包含每个项目的源科目、字段、金额、表达式和结果，可据此复算。
7. 审计摘要包含输入文件、映射配置、输出文件、日志文件的 SHA256。
8. 日志查看器可查看历史运行并导出计算明细 CSV。
9. 审计包可导出并包含第 2.9 节所列文件。
10. 单目录文件夹复制到无 Python 环境的 Windows 电脑可正常运行。
11. 全程无网络请求，断网环境功能正常。
12. 文件损坏、列缺失、输出目录不可写等异常不崩溃，有明确提示并记录异常日志。
